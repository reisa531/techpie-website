// FEATURES

为上科大日常打造的全栈校园工具

每个模块都围绕高频校园场景原生重构，点击任意卡片即可查看详细使用文档。

课表、自定义课程与考试安排

自动定位当前周次，支持自由添加和编辑自定义课程，学期考试直接整合进首页与周课表，并可一键导出标准 ICS 日历订阅。

阅读课表文档 →

Deadlines & 桌面小组件

聚合 Gradescope 与课程作业，提供倒计时进度条与迟交时间提示；支持 iOS / macOS 小中大尺寸桌面小组件实时同步。

阅读 Deadlines 文档 →

校园卡在线 / 离线付款码

原生还原上科大校园卡面，支持扫码支付、交易记录查询与手动离线模式，食堂断网也能安心刷码。

阅读校园卡文档 →

Apple Watch & 鸿蒙手表

同步授权后可独立获取在线与离线校园卡付款码，支持常亮显示与自动支付结果检查，抬腕即付。

阅读手表端文档 →

体育场馆预约

快速查看羽毛球、网球、匹克球等空闲场地，原生交互告别繁琐网页表单，约球更顺手。

阅读场馆预约文档 →

课程录播 ELRC

内置原生课程录播播放器，随时回看课堂录像与复习重点，支持倍速播放与断点续看。

阅读课程录播文档 →

GenAI API 与 eGate 会话保活

集成上科大校园 GenAI API 网关管理与验证，搭配 GeekPie SSO（Casdoor）与 eGate 自动续期机制，一次登录持久在线。

阅读 GenAI 与认证文档 →
