TechPie 功能文档

面向上海科技大学同学的使用说明、特性介绍与多平台安装参考。

课表 & 考试安排

Schedule

绑定上科大 eGate 账号后，TechPie 会自动同步本学期课表与考试信息，并在打开周课表时自动定位到当前教学周。

  • 支持添加、编辑和删除自定义课程（按学期、星期、周次与节次灵活排布）。
  • 学期考试自动展示在首页课程安排与周课表中，地点清晰提取，不混杂冗余文本。
  • 支持将课表与自定义课程、考试一键导出为标准 .ics 日历文件，轻松同步至系统日历。

Deadlines 截止事项

Assignments

统一聚合 Gradescope 作业与学期考试截止时间，按紧迫度智能分组，避免遗漏任何 DDL。

  • 提供直观的剩余时间倒计时与进度条，临近截止自动红色高亮提醒。
  • 完整支持 Gradescope 迟交截止时间（Late Due Date）显示。
  • 支持标记已完成或隐藏/忽略事项，状态实时同步至桌面小组件；切换或退出账号时自动清理旧数据。

校园卡付款码

Campus Card

原生复刻上海科技大学校园卡面，集成在线与离线双模式付款码、扫码支付与消费账单查询。

  • 支持手动切换并记住离线模式，弱网或断网环境下自动使用有效离线授权码。
  • 支持桌面小组件或长按 App 快捷方式直达付款码，支付成功附带清晰的金额与振动反馈。
  • 默认启用个人信息模糊保护，点击可临时查看，保护屏幕隐私。

体育场馆预约

OA Gym

直接在原生界面浏览上科大体育馆空闲场地与时段，支持羽毛球、网球、匹克球等热门场馆预约。

  • 准确映射网球与匹克球共用场地状态，实时刷新空闲时段。
  • 自动补齐 eGate 绑定的学号信息，免去重复填写表单。

课程录播 ELRC & E云课堂

ELRC

内置原生课程录播列表与播放器，并整合 E云课堂 Cookie 免登入口，随时随地回看课堂内容。

  • 无需手动复制粘贴 Cookie，自动复用已保活的校园会话。
  • 原生播放器体验流畅，适配移动端与桌面端窗口尺寸。

GenAI API 与统一认证

GenAI & Auth

原生接入校园 GenAI API 网关，配合 GeekPie SSO（Casdoor）与 /api/auth/renew 自动续期机制，提供一站式密钥与会话管理。

桌面小组件

Widgets

支持 iOS 与 macOS 原生桌面小组件，无需打开 App 即可在主屏幕一览接下来的 DDL 与快速调出校园卡。

  • Deadlines 小组件提供小、中、大三种尺寸，展示作业与考试名称、截止时间、剩余天数/小时及考试地点。
  • 使用本地缓存即时渲染，与应用内完成/忽略操作实时同步，点击直达对应页面。

Apple Watch & 智能手表

Wearables

与手机端同步授权后，手表端可独立运行校园卡付款码，支持 Apple Watch 与华为鸿蒙手表。

  • 联网时优先请求在线付款码并自动轮询支付结果；断网时自动降级至有效离线授权码。
  • 支持保存默认在线/离线偏好，进入常亮显示或短暂切后台时保持有效付款码不丢失。

全平台安装指南

Installation

TechPie 统一使用 Flutter 构建，在所有主流桌面与移动平台均提供预编译产物：

# Arch Linux (AUR) yay -S techpie-bin # 或前往 GitHub Releases 获取各平台最新安装包： # https://github.com/HeZeBang/TechPie-flutter/releases/latest
iOS / macOS 用户推荐使用 TestFlight 获取自动更新；Linux 用户也可按需选择 AppImage、Flatpak 或 tar.gz。
